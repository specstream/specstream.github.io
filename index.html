SpecStream open source

SpecStream is the live web data engine. Ask for data in plain words and get structured rows from the live web, with a source URL for each value. These are the open source pieces that put it inside the tools you already use.

Repositories

  • browser-agent

    A browser agent in one Python file: Claude drives a real Chromium on a SpecStream browser session.

  • search-web-skill

    An agent skill that searches the live web through SpecStream.

  • jarvis-specstream

    SpecStream web search and page extraction for Jarvis.

  • specstream-tools

    SpecStream inside Tools.

  • odoo-specstream

    SpecStream inside Odoo.

  • status

    Uptime monitor and status page for the SpecStream APIs

  • google-custom-search-api-shutdown

    Open-source AI apps that still call Google's Custom Search JSON API, which ends January 1, 2027: the file and line in each, what each project has said, and a script that checks again.

  • specstream-cursor-plugin

    SpecStream for Cursor: live web search, page extraction and Deep Search through the SpecStream MCP server

  • find-action

    A GitHub Action that runs a SpecStream request and uploads the results as a CSV.

  • obsidian-specstream

    SpecStream inside Obsidian.

  • hermes-web-specstream

    SpecStream Search API (the most accurate web search API in the world, specstream.ai/benchmarks) and Extract API as a web_search and web_extract backend for Hermes Agent
